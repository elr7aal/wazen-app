# وازن | WAZEN

**وازن** مشروع تطبيق للمساعدة في تنظيم التغذية اليومية ومتابعة التقدم نحو أهداف صحية شخصية.

## حالة المستودع

هذا المستودع في مرحلة الإعداد. لم تُرفع ملفات التطبيق بعد؛ لذلك لا توجد حالياً تعليمات تثبيت أو تشغيل أو بناء موثقة. سيُحدَّث هذا الملف بعد إضافة الشيفرة ومتطلبات التشغيل الفعلية.

## ما سيُوثَّق عند رفع التطبيق

- المتطلبات والبيئة اللازمة للتطوير.
- إعداد المشروع وتشغيله محلياً.
- طريقة تجربة نسخة iOS على جهاز فعلي.
- إعدادات الخدمات الخارجية والمتغيرات المطلوبة، من دون نشر بيانات سرية.
- أوامر الفحص والاختبار وآلية إصدار النسخ.

## المساهمة

يمكن تسجيل الملاحظات والأخطاء والتحسينات المقترحة عبر Issues في هذا المستودع. يرجى عدم إرفاق بيانات صحية شخصية أو مفاتيح وصول ضمن البلاغات.

## الترخيص

لم يُحدَّد ترخيص للمشروع بعد. جميع الحقوق محفوظة إلى حين إضافة ملف ترخيص يوضح شروط الاستخدام.
